# Contributing

Thanks for checking out `ScreenshotApp`.

This is a small app I use daily and share as open source. Contributions are welcome.

## Before You Start

- For bugs and ideas, open an issue first.
- For larger changes, open an issue before writing code so we can align scope.

## Pull Requests

- Keep PRs focused and small.
- Explain what changed and why.
- Link the related issue when possible.

## Local Validation

Before opening a PR, run:

```bash
swift build
swift test
```

## Decision Policy

This project is maintainer-led. Feedback and ideas are welcome, and I decide what fits the app direction.
